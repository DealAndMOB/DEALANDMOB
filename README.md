### [Ejercicios de lógica en JavaScript](https://github.com/DealAndMOB/javascript-programming-challenges)

Colección organizada por niveles con ejercicios de lógica, algoritmos, estructuras de datos y proyectos prácticos. Incluye documentación, guía de contribución, código de conducta y licencia MIT.

### Sistema de punto de venta

Aplicación multitenant desarrollada con Laravel para administrar productos, inventario, ventas, pagos y cortes de caja. Incluye roles, movimientos de inventario, cancelaciones controladas, tickets, reportes y pruebas de los flujos críticos.

### Plataforma de gestión para barberías

Sistema para gestionar reservaciones, agenda, clientes, personal, sucursales y operación financiera. Integra acceso mediante OTP, invitaciones de equipo, cobros, devoluciones, reportes, códigos QR y auditoría de eventos.
